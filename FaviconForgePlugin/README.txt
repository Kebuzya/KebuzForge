FaviconForge Plugin для KebuzForge
==================================

Установка:
1. Откройте KebuzForge.
2. Меню "Плагины" -> "Открыть папку плагинов..."
3. Скопируйте FaviconForgePlugin.dll в открывшуюся папку Plugins.
4. Снова откройте меню "Плагины" - пункт "Favicon Generator" появится в списке.

Возможности:
- favicon.ico (16/32/48) и favicon PNG 16x16, 32x32, 48x48
- apple-touch-icon.png 180x180 (iOS) + имя приложения для Apple
- android-chrome 192x192 / 512x512 + PWA maskable icon, name и short name
- Windows Tiles (mstile 70/144/150/310x150/310x310) + browserconfig.xml
- safari-pinned-tab.svg (монохромный силуэт)
- site.webmanifest и готовый HTML-код для <head>
- Реалистичные превью: вкладка браузера и поиск (светлая/тёмная тема),
  рабочие столы Apple и Android, Android Splash и переключатель задач,
  плитка Windows, Safari Pinned Tab
- Настройки фона, отступов, скругления, цветов темы и плитки
- Переключение языка RU/EN вместе с приложением
- Экспорт пакета в ZIP или папку
